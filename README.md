# sabara.org

Minimal static landing page for **sabara.org**.

## Files

- `index.html` — homepage
- `style.css` — styling
- `assets/` — logo and icons
- `CNAME` — GitHub Pages custom domain

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `sabara.org`.
2. Upload all files from this folder to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. GitHub Pages will publish the site.
7. Under **Custom domain**, confirm `sabara.org` if GitHub does not detect it automatically.

You will still need to point the DNS records of the domain to GitHub Pages in your domain/DNS provider.
